# WO-000 — Índice Maestro de Especificación de Producto ADÁN (v3.6)

**Tipo de documento:** Árbol documental — **APROBADO Y CONGELADO** (sin cambios de estructura desde v3.1).
**Estado de la WO-000:** El núcleo filosófico (AD-000 a AD-004 + Anexo de Meta-Principios) queda íntegramente aprobado y congelado. Se ejecutó un Enterprise Taxonomy Workshop (documento de trabajo, no forma parte del árbol) como preparación de AD-005.
**Supersede a:** `WO-000_INDICE_MAESTRO_v3.5.md`.
**Naturaleza de este cambio:** de proceso — cierre de fase, no cambio estructural.

---

## 0. Qué cambió respecto a v3.5

1. `AD-004` y el Anexo de Meta-Principios quedan **aprobados y congelados**.
2. Se introduce la categoría de **Documentos de Trabajo** (`docs/wo-000/workshops/`): artefactos de descubrimiento que no forman parte del árbol de 58, no llevan código AD-XXX, no se aprueban ni se congelan — sirven exclusivamente de materia prima para el documento que sí se congela. El primero es el `Enterprise Taxonomy Workshop`.
3. Se introduce el trabajo **por ciclos** en vez de documento por documento, a partir de AD-005: *Ciclo Dominio* (Workshop de Taxonomía → Workshop de Relaciones → Workshop de Comportamientos → AD-005 → AD-006 → AD-007), seguido de *Ciclo Producto* y *Ciclo UX*, cada uno como una unidad de revisión, no cada documento aislado.
